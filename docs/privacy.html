Política de Privacidad

Última actualización: 2026

Esta política de privacidad corresponde a "Automatizacion Ads", un proyecto personal de automatización descrito en la página principal de este sitio. No es un producto comercial ni un servicio ofrecido a terceros: es una herramienta de uso individual, operada y utilizada exclusivamente por su autor.

Qué datos se procesan

La herramienta consulta, mediante la API de Google Ads, métricas agregadas de campañas publicitarias (nombre de campaña, impresiones, clics y costo) pertenecientes a la propia cuenta publicitaria del autor. No se recopilan, almacenan ni procesan datos personales de terceros, visitantes u otros usuarios.

Cómo se usan los datos

Los datos obtenidos se utilizan únicamente para generar reportes internos de rendimiento publicitario para uso propio. No se comparten con terceros, no se venden, y no se utilizan con fines distintos al análisis interno descrito.

Almacenamiento

Los reportes generados se almacenan como archivos dentro de un repositorio privado de control de versiones (GitHub), con acceso restringido a su autor. Las credenciales de acceso a las APIs utilizadas se gestionan como secretos cifrados dentro de la plataforma de GitHub y no se exponen en el código ni en ningún archivo público.

Contacto

Ante cualquier consulta sobre esta política, se puede escribir a automation.ggscripts@gmail.com.
