Automatización de reportes de marketing digital

Un flujo propio que convierte pedidos simples en reportes y código, usando GitHub como sistema de revisión. No es un producto comercial: es un proyecto personal para automatizar tareas repetitivas de mi propio trabajo.

Qué es esto

Este proyecto es un script personal que corre sobre GitHub Actions. Cuando necesito un reporte o una pequeña automatización, abro un pedido en el repositorio; un modelo de lenguaje genera el resultado (código o un archivo de datos) y lo deja listo en una rama nueva para que yo lo revise antes de aceptarlo. Nada se aplica sin mi aprobación manual.

Quién lo usaUna sola persona: yo. No tiene otros usuarios ni clientes.
Para quéAutomatizar reportes y tareas propias de marketing digital y análisis de datos.
Dónde viveUn repositorio privado de GitHub, con revisión humana obligatoria en cada cambio.

Cómo funciona

  1. Pedido Abro un issue describiendo qué reporte o script necesito.
  2. Autorización Aplico manualmente una etiqueta (auto-generate o google-ads-report) para habilitar la ejecución. Nada corre sin esa autorización explícita.
  3. Generación El flujo consulta la fuente correspondiente en modo de solo lectura y arma el entregable (código o archivo de datos).
  4. Revisión El resultado se sube a una rama nueva y se abre un pull request. Lo reviso y decido si lo apruebo o lo descarto.

Alcance del acceso a Google Ads

El uso de la API de Google Ads dentro de este proyecto está limitado a consultas de solo lectura (método search) sobre mi propia cuenta publicitaria, para extraer métricas de campañas (impresiones, clics, costo) de los últimos 30 días.

No se realiza ninguna operación de escritura, modificación o gestión de campañas, presupuestos ni configuraciones. La cuenta usada para autenticar el acceso tiene permiso de solo lectura dentro de Google Ads.

Proyecto personal, sin fines comerciales ni de distribución. Código y flujo alojados en github.com/automationggscripts/testing.
